# Codex Queue Studio v3.3.0 Preview

Windows 11 네이티브 UI·세션 목록 갱신·스마트 릴레이 시험 릴리스입니다.

## 이번 버전

- **세션 목록 안정화:** 전체 창을 4초마다 다시 그리지 않습니다. 변경되지 않은 세션 행은 유지합니다.
- **사용자 상태 유지:** 세션 선택 상태와 가상화 목록의 스크롤 위치를 최대한 유지합니다.
- **갱신 병합:** 세션 검색 중 새로고침 요청을 중첩 실행하지 않습니다.
- **스마트 릴레이:** Codex 작업 세션의 완료 이벤트를 감지합니다.
- **API 채팅 검토:** OpenAI API Conversations/Responses에 결과를 전달하고 검토 답변을 받습니다.
- **선택적 재전송:** AI 답변을 Codex 작업 세션에 다시 보내는 기능을 선택할 수 있습니다.
- **사용자 승인:** 답변을 보여주고 승인받은 뒤 전송하는 옵션이 기본값입니다.
- **안전한 기록:** 처리한 턴 ID와 상태를 저장하고, 비정상 종료 후 중복 전송을 방지합니다.
- **반복 제한:** 자동화 규칙의 기본 반복 한도는 3회입니다.
- **Windows UI:** 새 스마트 릴레이 네이티브 창을 추가했습니다. 기존 Windows 11 창 버튼과 독립 실행 방식을 유지합니다.

## 배포 파일

| 파일 | 사용 목적 |
|---|---|
| `CodexQueueStudio-Windows-x64.zip` | Windows 전체 프로그램 및 Codex 실행 엔진 포함 |
| `CodexQueueStudio-update-Windows-x64.zip` | 자동 업데이트 전용 프로그램 및 SHA-256 매니페스트 |

두 파일은 동일한 v3.3.0 바이너리에서 생성됩니다. 릴리스 작업은 파일 수와 SHA-256 체크섬을 검사합니다.

## 주의 사항

이 버전은 **Preview**입니다. 실제 사용자 PC에서 ChatGPT 앱 대화에 직접 메시지를 보내는 기능은 없습니다. 별도 OpenAI API 대화를 사용하며 `OPENAI_API_KEY`가 필요합니다. ChatGPT 구독료와 API 비용은 별도입니다.

Codex `task_complete` 이벤트는 턴 종료를 뜻합니다. 프로그램 작업 전체가 성공했음을 보증하지 않습니다. 결괏값을 검토하고 필요한 경우 사용자 승인을 사용하세요.

기존 예약 데이터 `%LOCALAPPDATA%\CodexQueueStudio\state.json`을 삭제하지 마세요. 자동화 규칙을 만들지 않으면 스마트 릴레이는 실행되지 않습니다.

설정과 제한 사항은 `docs/SMART_RELAY_PREVIEW.md`를 확인하세요.
