# Codex Queue Studio v3.4.0 Preview

이번 릴리스는 세션 탐색기와 스마트 릴레이의 선택 흐름을 전면 정리한 Windows 11 네이티브 UI 시험 버전입니다.

## 사용자 기능

- **세션 탐색기 2개 탭:** Codex 작업과 GPT 채팅(API)을 분리합니다.
- **GPT API 대화 기록:** 프로그램에서 생성하거나 스마트 릴레이에 등록한 API 대화의 메시지를 조회합니다.
- **스마트 릴레이 선택 UI:** 작업 세션 UUID를 직접 입력하지 않고 이름·프로젝트를 보고 선택합니다.
- **API 채팅 선택 UI:** 새 API 대화를 자동 생성하거나 등록된 대화를 선택합니다.
- **검토 모델 선택:** OPENAI_API_KEY로 현재 계정의 모델 목록을 조회하고 콤보박스에서 선택합니다.
- **모델 유효성:** 오디오·이미지·임베딩 등 명백히 맞지 않는 모델을 목록에서 제외합니다. 실제 Responses API 지원은 요청 시 확인됩니다.
- **네이티브 UI 디테일:** Win11 기본 창 버튼, 자연스러운 카드 계층과 여백, 라이트·다크 색 대비, 210ms 탭 이동 및 175ms 릴레이 창 등장 효과를 적용했습니다.
- **접근성:** Windows 애니메이션 비활성화 설정을 존중합니다.
- **화면 깜박임 억제:** 가상화 목록 변경 항목만 다시 그리며, 탭 애니메이션은 해당 작은 영역만 갱신합니다.
- **확장 구조:** AI 제공자 등록 인터페이스, 모델 조회, 대화 생성·기록·검토 책임을 분리했습니다. Grok·Gemini·Claude 어댑터는 아직 구현되지 않았습니다.
- **기존 데이터 보존:** 예약 작업, 릴레이 규칙 및 암호화 데이터의 기존 JSON 필드는 유지합니다.

## 제공 파일

| 파일 | 포함 항목 |
| --- | --- |
| `CodexQueueStudio-Windows-x64.zip` | 프로그램, 업데이터, 공식 Codex 실행 엔진, 설명서 |
| `CodexQueueStudio-update-Windows-x64.zip` | 프로그램 EXE, 업데이터 EXE, SHA-256 매니페스트 |

릴리스 자동화는 두 파일을 모두 생성하고 GitHub에 업로드한 뒤 존재 여부와 체크섬을 확인합니다.

## 주요 제한

**GPT 채팅 탭은 기존 ChatGPT 웹·앱 채팅 목록을 읽지 않습니다.** OpenAI API Conversations로 생성하거나 연결한 대화만 보여줍니다.

ChatGPT 구독과 OpenAI API 사용 요금은 별개입니다. API 채팅 자동화를 사용하려면 `OPENAI_API_KEY`를 Windows 환경 변수로 설정하고 앱을 다시 실행하세요.

모델 목록은 계정별로 다릅니다. 목록에서 표시되더라도 모델이 Responses API의 모든 기능을 지원한다는 의미는 아닙니다.

프로그램의 종료·절전 중 예약 실행과 모든 AI 업체 간 메시지 전송은 보장되지 않습니다.

## 검증

GitHub Actions에서 Go 단위 테스트·Race Detector·Windows GUI 빌드·시작 검사·네이티브 탭과 릴레이 컨트롤 검사를 수행합니다. 실제 Windows 11 환경의 화면 품질과 인증된 API/실제 Codex Desktop 왕복 작업은 추가 확인이 필요합니다.

설계와 수동 검증 항목은 `docs/ARCHITECTURE_3_4.md`에서 확인하세요.
