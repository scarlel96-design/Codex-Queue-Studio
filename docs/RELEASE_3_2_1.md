# Codex Queue Studio v3.2.1 — Windows UI · 업데이트 안정화

이번 릴리스는 Windows UI 응답성 문제와 자동 업데이트 경험을 개선하는 **시험 버전**입니다.

## 주요 변경 사항

- **Windows 11 네이티브 UI:** Segoe UI Variable 글꼴, 색상 대비, 여백, 사이드바 강조, 상태 표시 및 둥근 구성 요소를 개선했습니다.
- **공식 릴리스 내역 표시:** 업데이트 확인 후 GitHub Release 본문의 변경 내역과 새 버전 정보를 확인할 수 있습니다.
- **다운로드 진행률:** 다운로드 용량, 검증 단계와 설치 준비 상태를 화면에 표시합니다.
- **별도 설치 창:** 파일 백업, 실행 파일 교체 및 새 버전 실행 검증 과정을 진행률과 함께 표시합니다.
- **무응답 감지:** 새 버전의 창 존재뿐 아니라 UI 스레드 준비 신호와 Windows 메시지 응답을 검사합니다.
- **자동 복구:** 새 버전이 시작 직후 종료되거나 응답하지 않으면 백업 파일로 복구를 시도합니다.
- **예약 보호:** 메시지 전송이 진행 중이거나 곧 실행할 예약이 있으면 업데이트를 중단합니다.
- **세션 선택 유지:** 새로고침 시 기존 세션을 가능한 한 유지합니다.
- **렌더링 최적화:** 예약 목록을 갱신할 때 모든 메시지를 다시 복호화하지 않습니다.

## 배포 파일

- `CodexQueueStudio-Windows-x64.zip`: 전체 설치 파일과 Codex 실행 엔진
- `CodexQueueStudio-update-Windows-x64.zip`: 자동 업데이트 전용 앱·업데이터·SHA-256 매니페스트

## 검증 시 주의사항

이 릴리스는 시험 버전입니다. 운영 PC에서 실제 예약 전송과 자동 업데이트를 검증해야 합니다. 기존 `%LOCALAPPDATA%\CodexQueueStudio\state.json`은 삭제하지 마세요. 정상적인 재설치에서도 예약 데이터는 유지합니다.

**v3.2.0이 이미 ‘응답 없음’이면** 앱 내부 업데이트 대신 전체 설치본에서 두 EXE를 교체하세요. 파일 교체 전에 작업 관리자에서 관련 프로세스를 모두 종료하세요.
