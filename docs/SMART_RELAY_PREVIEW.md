# 스마트 릴레이 — 사용자 안내 및 검증 조건

## 적용 범위

- **Codex 작업 세션:** 로컬 Codex rollout의 `task_complete` 이벤트를 감시합니다.
- **AI 검토 세션:** OpenAI API Conversations와 Responses로 유지합니다.
- **응답 재전송:** 사용자가 옵션을 활성화한 경우에만 Codex App Server로 보냅니다.
- **ChatGPT 일반 채팅:** 기존 ChatGPT 웹·앱 대화를 읽거나 수정하지 않습니다.

API Conversation ID(`conv_...`)와 ChatGPT 앱 채팅 ID는 서로 호환되지 않습니다.

## 설정 절차

1. Codex Queue Studio에서 Codex 작업 세션을 선택합니다.
2. **스마트 릴레이**를 열어 대상 세션 UUID를 확인합니다.
3. 기존 OpenAI API Conversation ID를 입력하거나 빈칸으로 둡니다.
4. API 모델 이름을 입력합니다.
5. 검토 지침을 입력하거나 기본값을 사용합니다.
6. 필요하면 **Codex로 다시 전송**을 선택합니다.
7. **사용자 승인** 옵션을 유지하는 것을 권장합니다.
8. **새 자동화 규칙 생성**을 누릅니다.

프로그램을 시작하기 전에 Windows 사용자 환경 변수 `OPENAI_API_KEY`를 설정해야 합니다. ChatGPT Plus 구독과 API 사용 요금은 별도입니다. API 키를 앱 데이터 파일이나 GitHub에 입력하지 마세요.

## 이벤트 및 중복 방지

1. 새 규칙은 생성 시점의 마지막 완료 턴을 기록합니다.
2. 프로그램은 해당 시점 이후의 `task_complete` 이벤트만 처리합니다.
3. 전송을 시작하기 전에 턴 ID와 실행 상태를 영구 저장합니다.
4. AI 검토가 끝나면 답변을 현재 Windows 사용자용 DPAPI로 암호화합니다.
5. **사용자 승인**이 켜져 있으면 대기 상태로 유지합니다.
6. **Codex 재전송** 옵션이 꺼져 있으면 검토에서 종료합니다.
7. 사용자 승인 없이 재전송하도록 명시적으로 선택한 경우에만 자동 전송합니다.
8. 기본 자동화 반복 한도는 **3회**입니다.
9. 프로그램이 실행 중 종료되면 미완료 요청은 **결과 불명**으로 전환합니다.
10. 결과 불명 상태의 요청은 자동 재실행하지 않습니다.

`task_complete`는 **턴 종료 이벤트**입니다. 프로젝트 목표 달성 또는 테스트 통과를 증명하지는 않습니다.

## 화면 깜박임 수정

- 변경되지 않은 세션 목록과 예약 목록을 다시 그리지 않습니다.
- 목록에 변화가 있으면 가상화 목록의 변경된 행만 갱신합니다.
- 전체 창을 4초 간격으로 계속 무효화하던 경로를 제거했습니다.
- 상태 표시줄이 바뀐 경우 해당 영역만 다시 그립니다.
- 동시에 여러 세션 새로고침이 실행되지 않도록 차단했습니다.
- Windows 11의 기본 창 최소화·최대화·닫기 버튼은 유지합니다.

## 운영 제약

- Windows가 절전 중이거나 프로그램이 종료되면 자동화가 실행되지 않습니다.
- API 요청과 Codex 전송은 네트워크와 인증 상태에 따라 실패할 수 있습니다.
- Codex Desktop과 별도의 App Server 프로세스가 같은 세션에 접근하면 충돌할 수 있습니다.
- 반복 실행은 모델 사용 비용과 코드 변경을 유발할 수 있습니다.
- 자동화는 기본 비활성화 상태이며 사용자가 규칙을 만들어야 시작합니다.
- 실제 사용자 PC에서의 Codex Desktop·API 종단 간 연동은 별도 검증해야 합니다.

## 승인 기준

- Linux 및 Windows Go 테스트 통과
- Windows GUI x64 빌드와 시작 테스트 통과
- 네이티브 릴레이 창 열기·닫기·목록 표시 수동 검증
- 작업 완료 이벤트 감지 → AI 검토 → 승인 → Codex 전달 수동 검증
- 오류 및 비정상 종료 후 중복 전송이 없는지 검증
