## AI 제공자 확장 계약

새 제공자는 `internal.ChatProvider`를 구현해야 합니다. 제공자는 모델 목록, 대화 생성, 대화 기록, 검토 응답을 처리합니다. `NewProviderRegistry`에 새 제공자를 등록하면 코어에서 접근할 수 있습니다. 공급자 인증과 모델 호환성 정책을 추가하고, 릴레이 UI의 제공자 선택도 연결해야 합니다.

Grok, Gemini, Claude는 **미구현** 상태입니다. 설계에 있는 이름만으로 실제 연동 기능을 주장하지 마세요.

## 데이터 구분

- Codex 작업 세션: Codex 로컬 저장소와 공식 App Server가 제공하는 데이터
- GPT 채팅: 사용자가 로컬에서 등록했거나 앱이 생성한 OpenAI API Conversation ID
- ChatGPT 앱 개인 채팅: 공식 API 대화와 별개이며 이 프로그램에서 자동 조회하지 않음

`ChatSession`은 `providerId`, `id`, `title`, 시간 메타데이터를 포함합니다. 기존 예약 작업 및 릴레이의 ID와 암호화된 메시지 데이터는 변경하지 않습니다.

## 수동 검증 시나리오

1. Windows 11에서 기본 제목 표시줄의 최소화·최대화·닫기 동작을 확인합니다.
2. 라이트·다크 테마를 전환하고, 세션 제목·목록·콤보박스의 대비를 확인합니다.
3. Codex/GPT 탭을 반복 전환하며 스크롤 위치·선택을 확인합니다.
4. Windows 애니메이션 설정을 끈 뒤 탭 전환과 릴레이 창 열기를 확인합니다.
5. API 키 없이 GPT 대화 생성과 모델 조회 오류 메시지를 확인합니다.
6. API 키를 등록한 후 계정 모델 목록을 조회합니다.
7. GPT 대화를 생성하고 앱 재실행 후 목록과 기록을 확인합니다.
8. Codex 작업 세션과 GPT API 대화를 이름으로 선택해 릴레이 규칙을 만듭니다.
9. 사용자 승인 모드로 작업 완료 → AI 검토 → 재전송을 검증합니다.
10. 네트워크 중단과 앱 비정상 종료 후 중복 전송을 차단하는지 확인합니다.
11. GitHub Releases의 전체 파일과 업데이트 파일 두 개, SHA-256 값, 업데이트 복구를 확인합니다.
12. 100~1000개 Codex 세션으로 목록 조회 성능과 메모리 사용을 점검합니다.

## 출시 판정

CI 통과는 실행 파일의 구축과 기본 구동을 확인합니다. 실제 UI의 고급스러움, GPU/화면 배율별 렌더링 및 실제 API 왕복 통신이 검증되지 않으면 **Preview**로 표기합니다.
